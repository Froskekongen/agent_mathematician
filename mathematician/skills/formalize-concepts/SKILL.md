# Formalize Concepts

Turn intended meaning into the simplest faithful mathematics through a
show-then-ask loop. Selection establishes semantic fit, not proof, uniqueness,
novelty, causal validity, or empirical confirmation.

## 1. Identify the mathematical job

Infer the user's relevant expertise from their definitions, notation,
examples, and corrections. Restate what the formalism should do—describe,
distinguish, predict, classify, optimize, control, or support a theorem—and
separate descriptive, causal, and normative meanings when they imply different
mathematics.

Complete this step when the job and one meaningful example support a first
proposal.

## 2. Show candidates

Present the simplest faithful candidate and normally one materially different
alternative. Add a third only when it exposes an independent interpretation;
develop one candidate directly when the user has already fixed the structure.
For each state the objects, central relation or rule, interpretation, feature
captured, and one consequence or limitation.

Complete this step when the user can judge a mathematical difference rather
than a vocabulary difference.

## 3. Ask one wedge question

Ask one high-leverage question per round, or two only when inseparable. Show
how each answer changes meaning, examples, admissible maps, or model class.
Make reversible technical choices with the simplest standard option. Pause on
a live material fork unless the user has resolved it, delegated it, or asked
for a one-shot proposal.

Complete this step when the fork is resolved or sharply preserved.

## 4. Test and select

Update the leading candidate and test one anchor example, one boundary case or
nonexample, and basic type and well-posedness conditions. Use a cheap derived
consequence when it helps distinguish meanings. Repeat only while a material
conceptual fork remains.

Treat clear endorsement, incorporated correction without further objection,
or explicit delegation as selection. Preserve serious alternatives with one
decisive reason each; discard cosmetic variants. Give each durable downstream
definition, mechanism, conjecture, or obstruction a human-semantic
lowercase-kebab research key for the receiving coordinator.

## Return and completion

Return the mathematical reading, selected formalism, anchor and boundary
checks, serious alternatives set aside, and unresolved questions or downstream
handoff. Use `PROVISIONAL` or `SELECTED` only when useful.

Complete when one candidate is selected or one exact semantic fork remains.
Hand substantial proof, necessity, empirical, causal, or novelty work to the
appropriate downstream skill; this skill creates no research database.
